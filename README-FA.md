# Lord Music — نسخه‌ی اندروید (Kotlin)

یه اپ اندروید که پلیر Lord Music رو داخل WebView اجرا می‌کنه.
فایل‌های وب داخل `app/src/main/assets` هستن؛ برای تغییر ظاهر یا امکانات همونجا ویرایششون کن.

APK رو GitHub Actions خودکار می‌سازه:
بعد از هر push، تو بخش Releases همین ریپو فایل `LordMusic.apk` میاد.
